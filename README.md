## Notes

This project demonstrates a complete React application with:
- React Router for navigation between dashboard and detail views
- Recharts library for data visualization (bar chart and pie chart)
- Responsive design that works on all devices
- Modern CSS with gradients and animations
- Detailed movie data with financial analysis, cast information, and awards

The dashboard features two interactive charts:
1. **Rating Comparison Chart**: Bar chart showing movie ratings for easy comparison
2. **Genre Distribution Chart**: Pie chart displaying the distribution of movie genres

Each movie card links to a detailed view with comprehensive information including budget, box office data, cast lists, plot summaries, and awards.
